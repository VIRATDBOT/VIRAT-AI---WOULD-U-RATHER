# 🎲 Would You Rather?! — AI Dilemma Duel

### 🔗 [**PLAY IT LIVE HERE**](https://viratdbot.github.io/VIRAT-AI---WOULD-U-RATHER/)

A fast, funny "Would You Rather" game with a VS-battle style — pick a vibe,
choose A or B, and see how the crowd split. Then reveal your "character"
based on the choices you made, and see how your streak stacks up.

## Features

- 🎭 5 categories: Chaotic, Wholesome, Cursed, School Life, Apocalypse
- 🔮 "Reveal My Character" — a personality readout based on your picks
- 🏁 Full game loop — play, end the game, see your final result
- 📱 Works on any phone or laptop — no install needed, just open the link
- 🎨 Custom VS-battle design, built from scratch

## Tech

Plain HTML, CSS, and JavaScript — no frameworks, no build step. Hosted for
free with GitHub Pages.

## Run it yourself

Just clone this repo and open `index.html` in any browser. No setup needed.

```bash
git clone https://github.com/viratdbot/VIRAT-AI---WOULD-U-RATHER.git
```
